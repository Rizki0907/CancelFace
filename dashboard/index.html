Evaluasi komprehensif terhadap ketahanan protokol CancelFace melawan ancaman siber, termasuk Serangan Rekonstruksi (mengembalikan wajah dari template) dan Serangan Inferensi Atribut (menebak identitas demografis).
Serangan Rekonstruksi Wajah
Cosine Similarity antara Wajah Asli dan Template Curian
INTERPRETASI KEAMANAN
Metrik Cosine Similarity = 0.11 membuktikan bahwa wajah yang direkonstruksi secara matematis tidak memiliki kemiripan dengan wajah asli. Jika Attacker men-reverse engineer template curian, mereka hanya mendapat *noise* acak.
Serangan Penebakan Atribut

INTERPRETASI KEAMANAN
Akurasi penebakan Gender jatuh ke angka ~57%. Secara statistik, ini setara dengan menebak secara acak (melempar koin). Ini membuktikan bahwa Gradient Reversal Layer (GRL) sukses membuang informasi sensitif.

Arsitektur ProposedNet (CancelFace)
Struktur Jaringan Adversarial
INPUT Embedding RP (512-dim) →
Linear(512→256) + BatchNorm + LeakyReLU(0.1)
Residual connection: fc_res = Linear(512→256)
Linear(256→256) + BatchNorm + LeakyReLU(0.1)
+ Residual skip connection dari input
ArcFace Head
Identity Loss
Softmax + Cosine Margin
GRL Head
Adversarial Loss
Gender + Age Classifier
OUTPUT: LSH Projection → Template Biner (256-bit)
Dikalikan matriks ortogonal berdasarkan INSTITUTION_KEY_SEED
Fungsi Loss Adversarial
L_identity (ArcFace Margin)
Cross-entropy pada embedding + cosine margin. Memastikan template yang berbeda orang tetap bisa dibedakan meski sudah diacak.
L_adv (Gradient Reversal)
GRL membalik gradien classifier atribut (gender/age), memaksa jaringan untuk melupakan informasi sensitif tersebut selama backpropagation.
L_triplet (Margin=0.35)
Memastikan jarak antar-identitas ≥ 0.35 dalam ruang embedding, membentuk cluster yang terpisah jelas.
Warmup Strategy (10 Epochs)
10 epoch pertama GRL dinonaktifkan (λ=0) agar identitas terkunci dahulu. GRL baru diaktifkan setelah anchor identitas stabil.
Kepatuhan ISO/IEC 24745
✓ LULUS
1. Non-invertibility
Tidak mungkin merekonstruksi embedding asli dari template terlindungi. Diverifikasi via serangan decoder: cosine similarity antara embedding asli dan rekonstruksi < 0.2 untuk CancelFace.
✓ LULUS
2. Revocability
Template bocor dapat dicabut dengan mengganti kunci (REVOCATION_KEY_SEED = 20260999). Template lama dan baru diuji: cosine similarity ≈ 0 (tidak ada korelasi).
✓ LULUS
3. Unlinkability
Template dua orang berbeda tidak dapat dihubungkan. Diuji via KS-test antara distribusi skor mated vs unmated: p-value << 0.05 dan overlap minimal.
✓ LULUS
4. Performance Preservation
Akurasi identifikasi (Rank-1) tidak turun signifikan setelah proteksi. CancelFace mempertahankan performa terbaik dibanding baseline RP dan BioHashing.
